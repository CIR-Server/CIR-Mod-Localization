# 参与维护 / Contributing

欢迎通过 Issue 或 Pull Request 提交补译、译名纠错、指南修订和署名补充。
Translation additions, terminology corrections, guide fixes and attribution updates are welcome through issues or pull requests.

- 标明模组、版本、语言键或文件路径，并说明修改理由。/ Identify the mod, version, language key or path, and explain the change.
- 保留原有署名；引用新来源时提供来源链接与许可。/ Preserve credits and include the source and license for newly imported material.
- 新增贡献者时，先确认公开名称、可选 GitHub 账号及贡献范围，再更新 CONTRIBUTORS.md。不要未经同意公开私人邮箱。/ Confirm the public name, optional GitHub account and contribution scope before updating CONTRIBUTORS.md; do not publish a private email without consent.
- 新增内容应遵循对应文件的许可；CIR 原创补译采用 CC BY-NC-SA 4.0。/ Follow the applicable file license; original CIR localization contributions use CC BY-NC-SA 4.0.
- 保持语言 JSON 有效，并使用 UTF-8。/ Keep language JSON valid and use UTF-8.

原作者的后续署名和共同维护安排保持开放，由维护者在收到回应后补充；公开署名不自动授予仓库写入权限。
Future original-author credits and joint-maintenance arrangements remain open and will be added after confirmation; public credit does not automatically grant repository write access.
